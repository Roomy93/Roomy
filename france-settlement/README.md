# France Settlement & Long-Term Housing Guide

이 문서는 `LFlem/StartinFr`의 방향성처럼 프랑스에 정착하는 외국인 학생을 위한 절차형 가이드를, Roomy의 상황에 맞게 확장한 것이다.

## 0. 현재 기준

- 목적: 프랑스 장기 숙소 확보 및 정착 준비
- 지역: Versailles / Le Chesnay / ISIPCA 접근 가능 지역
- 입학 예정: ISIPCA, 2026년 9월
- 입주 희망: 2026년 9월 초
- 체류 형태: 학생 / 약 1년 거주 예상
- 우선순위: 공식 계약서, CAF/APL 가능성, 교통 접근성, 보증 방식, 총비용 확인

---


## 2. 숙소 찾을 때 확인할 핵심 조건

### 필수 조건

- [ ] 2026년 9월 초 입주 가능 여부
- [ ] 최소 9개월~1년 거주 가능 여부
- [ ] 공식 임대계약서 제공 여부
- [ ] CAF/APL 신청 가능 여부
- [ ] 보증 방식: Visale 가능 / 해외 보증인 가능 / 보증금 조건
- [ ] 월세에 포함된 항목: 전기, 난방, 수도, 인터넷, 관리비
- [ ] 정확한 주소 또는 ISIPCA까지 이동 시간
- [ ] 곰팡이, 습기, 소음, 치안 문제 여부

### 있으면 좋은 조건

- [ ] 가구 포함
- [ ] 세탁기 또는 세탁시설
- [ ] 주방 독립 사용 가능
- [ ] 버스/기차역 접근성
- [ ] 마트, 약국, 병원 접근성
- [ ] 영상 투어 또는 최근 사진 제공

```text
Bonjour,

Je m'appelle Changhyeon Heo. Je suis un étudiant coréen et je vais commencer mes études à l'ISIPCA en septembre 2026.

- l'adresse exacte du logement ;
- si un bail officiel sera fourni ;
- si le logement est éligible à la CAF/APL ;

- si la garantie Visale ou un garant résidant en Corée peut être accepté ;
- ce qui est inclus dans le loyer : eau, électricité, chauffage, internet ;
- s'il serait possible de recevoir quelques photos récentes ou une courte vidéo du logement.

Changhyeon Heo
```

## 6. 프랑스 도착 후 정착 체크리스트

### 1주차

- [ ] 숙소 입주 및 état des lieux 확인
- [ ] 유심 또는 프랑스 전화번호 개통
- [ ] 은행 계좌 개설 예약
- [ ] Navigo / 교통카드 준비
- [ ] 학교 위치 및 통학 루트 확인

### 2~4주차

- [ ] CAF/APL 신청
- [ ] Assurance habitation 가입
- [ ] 사회보장 / Ameli 또는 étudiant étranger 절차 확인
- [ ] OFII 또는 비자 검증 절차 필요 여부 확인
- [ ] 학교 행정 등록 완료

---

## 7. 사기 방지 체크

- 계약 전 현금 송금 요구는 위험
- 주소 비공개 + 사진 부족 + 빠른 송금 요구 조합은 위험
- 집주인 신분증만 믿고 송금하지 않기
- 공식 계약서 없이 APL 가능하다는 말은 신뢰도 낮음
- 시세보다 지나치게 저렴한 매물은 추가 검증 필요
- 영상통화 또는 현장 방문 대리 확인 권장
